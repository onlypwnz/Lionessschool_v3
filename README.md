# Lioness International Beauty School

Лендинг школы перманентного макияжа и beauty-направлений в Алматы. Цель сайта — заявки на обучение.

Сейчас готовы только шапка и первый экран. Остальные разделы будут добавляться пошагово.

## Структура

- `index.html` — разметка шапки, Hero и якорных заглушек будущих разделов
- `style.css` — фирменный стиль, адаптив и микроанимации
- `script.js` — мобильное меню и состояние шапки при прокрутке

## Как открыть локально

Самый простой способ: открыть файл `index.html` двойным щелчком в браузере.

Через локальный сервер (удобнее для проверки якорей и путей):

```bash
python -m http.server 8080
```

Затем открыть в браузере: [http://localhost:8080](http://localhost:8080)
